Wi-Fi-Roll Guide

General Usage Guide

Connect the Wi-Fi-Roll to a power supply via USB-C; phone chargers or power banks work fine.

You're all set to Wi-Fi-Roll people!

If you want to taylor the experience, then connect to the access point the Wi-Fi-Roll generates.

Enter https;//http://wifi.lan/admin in your web browser to connect to the admin page of the Wi-Fi-Roll. From here you will be ablt to change the SSID, choose and upload different videos, mute the buzzer and more.

Some changes you make may not take effect until the device has rebooted.

Video Trim and Shrink.

Videos you want to add to the device will need to be compressed. Use the trim and shrink tool to make videos Wi-Fi-Roll friendly.

Mp4 files around 8-10 seconds long work best.

When converted vidoes can be easily uploaded via the Wi-Fi-Roll admin page.

More pre-made videos are on the videos page.
